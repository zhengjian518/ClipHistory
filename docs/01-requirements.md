# 产品需求文档（PRD）

> 项目名称：ClipHistory — Mac 历史粘贴板  
> 版本：v1.0  
> 最后更新：2026-06-02

---

## 1. 产品目标

在 macOS 菜单栏运行的剪贴板历史工具，让用户随时回溯、重用近期复制过的文字和图片，减少因内容覆盖导致的重复操作。

---

## 2. 用户画像

- 普通 Mac 用户，无编程背景
- 日常频繁复制粘贴文字和图片
- 重视隐私，不希望密码等敏感内容被记录

---

## 3. 核心功能需求

### 3.1 剪贴板监听
- 自动监听系统剪贴板变化
- 支持内容类型：**纯文字**、**图片**
- 相同内容连续复制时，只保存一次（去重）

### 3.2 历史记录管理
- 最多保留 **100 条**记录（超出自动删除最旧的未置顶记录）
- 可配置保留时长：**1 天 / 3 天 / 5 天**（默认 3 天）
- 置顶记录不受时长限制，永久保留直到手动删除

### 3.3 界面功能
- 点击菜单栏图标弹出历史面板
- 历史记录按**时间倒序**排列，置顶记录始终在最顶部
- 每条记录支持：
  - **点击** → 将内容写回剪贴板并模拟 Cmd+V 粘贴到当前应用
  - **置顶** → 固定在列表最顶部（再次点击取消置顶）
  - **删除** → 从历史中移除该条记录
- **搜索**：顶部搜索栏，实时过滤文字内容

### 3.4 隐私保护
- 自动跳过来自密码管理器的内容（见技术规范）
- 置顶记录不受保留时长清理

---

## 4. 非功能需求

| 项目 | 要求 |
|---|---|
| 启动方式 | 手动启动（不随系统登录自启） |
| 界面风格 | 简洁、直观，淡蓝色主色调 |
| Dock 图标 | 不显示（纯菜单栏应用） |
| 系统兼容性 | macOS 13 Ventura 及以上 |
| 性能 | 后台运行 CPU 占用 < 1%，内存 < 50MB |
| 数据存储位置 | 本地，~/Library/Application Support/ClipHistory/ |

---

## 5. 明确不做的功能（v1.0 范围外）

- 开机自动启动
- iCloud 同步
- 多设备共享
- 快捷键呼出
- 富文本（RTF）格式记录
- 文件/文件夹路径记录
