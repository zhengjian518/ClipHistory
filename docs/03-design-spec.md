# UI/UX 设计规范

> 项目名称：ClipHistory  
> 版本：v1.0  
> 最后更新：2026-06-02

---

## 1. 设计原则

- **简洁**：界面只展示必要信息，无冗余元素
- **直观**：操作一目了然，无需说明书
- **克制**：颜色不超过 3 个，留白充足

---

## 2. 配色方案

| 名称 | Hex | 用途 |
|---|---|---|
| 主色（淡蓝） | `#5B9BD5` | 按钮、强调、边框 |
| 置顶卡片背景 | `#EBF3FB` | 置顶卡片的浅蓝填充 |
| 卡片背景 | `.systemBackground` | 普通卡片（自动适配深色模式） |
| 卡片边框 | `#5B9BD5` @ 30% | 普通卡片边框 |
| 文字主色 | `.primary` | 内容文字（自动深色适配） |
| 文字辅色 | `.secondary` | 时间戳、来源 App 名称 |
| 背景底色 | `.windowBackground` | Popover 背景 |

深色模式：SwiftUI 语义色自动适配，主色和置顶背景在深色下自动加深。

## 4. 卡片设计

### 文字卡片

```
┌── 圆角 10pt，边框 1pt ────────────────────┐
│                              [📌] [🗑]    │
│ 这是复制的文字内容，最多显示三行，超出     │
│ 部分用省略号截断...                        │
│                                            │
│  来自 Safari · 14:32                       │← 辅色，小字
└────────────────────────────────────────────┘
```

- 内边距：12pt 四边
- 文字：系统字体，正文 14pt，时间戳 11pt
- 行数限制：`.lineLimit(3)`
- 点击整张卡片触发粘贴

### 图片卡片

```
┌── 圆角 10pt，边框 1pt ────────────────────┐
│                              [📌] [🗑]    │
│  ┌──────────────────────┐                 │
│  │   图片缩略图          │                 │← 高度固定 80pt，宽度自适应
│  │   （等比例缩放）      │                 │
│  └──────────────────────┘                 │
│  来自 Finder · 09:15                       │
└────────────────────────────────────────────┘
```

### 置顶卡片
- 背景填充 `#EBF3FB`（深色模式自动适配）
- 置顶图标使用 SF Symbol `pin.fill`（填充状态）
- 普通状态使用 `pin`（轮廓状态）

### 按钮规格
- 尺寸：24×24pt，点击区域 32×32pt
- 颜色：`.secondary`（默认），主色（hover/激活）
- 删除按钮 hover 时变红色（`.red`）

## 5. 搜索栏

```
┌─ 灰色圆角背景 ──────────────────────────────┐
│  🔍  搜索历史记录...                    [✕]  │
```

- 清除按钮：搜索框有内容时才显示 `✕`
- 占位文字：`搜索历史记录...`

## 7. 空状态

当没有任何历史记录时（首次启动或全部清空）：

```
         （剪贴板图标，48pt，灰色）
         暂无复制记录
         复制任意内容后将显示在这里
```

- 图标：SF Symbol `doc.on.clipboard`，`.secondary` 色
- 文字：`.secondary`，居中

---

## 8. 菜单栏图标

- SF Symbol：`doc.on.clipboard`
- 尺寸：系统默认（约 18pt）
- 颜色：跟随系统菜单栏（自动深浅色适配）

---

## 9. 动效规范

- 卡片出现：`withAnimation(.easeOut(duration: 0.2))`
- 卡片删除：滑出 + 淡出
- Popover 弹出：系统默认动效（无需自定义）
- 列表滚动：系统默认弹性滚动

---

## 10. 字体规范

| 用途 | 字体 | 大小 |
|---|---|---|
| 卡片正文 | 系统默认（.body） | 14pt |
| 时间戳/来源 | 系统默认（.caption） | 11pt |
| 搜索框 | 系统默认（.body） | 14pt |
| 底栏统计 | 系统默认（.caption） | 11pt |
| 设置标题 | 系统默认（.headline） | 16pt |
